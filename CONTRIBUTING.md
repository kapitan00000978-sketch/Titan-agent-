# Contributing to Titan Agent

First off, thank you for considering contributing to Titan Agent! It's people like you that make this tool great.

## Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct. Please be respectful to all contributors and users.

## How Can I Contribute?

### Reporting Bugs

This section guides you through submitting a bug report for Titan Agent. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.

- **Check existing issues:** Before creating bug reports, please check existing issues to see if the problem has already been reported.
- **Provide clear steps:** Describe the exact steps to reproduce the problem.
- **Include context:** What version of Titan Agent are you using? What OS? What LLM Provider?

### Suggesting Enhancements

This section guides you through submitting an enhancement suggestion, including completely new features and minor improvements to existing functionality.

- **Use a clear title:** Describe the suggestion clearly in the issue title.
- **Describe the current behavior:** Explain how the feature currently works and why you want to change it.
- **Describe the new behavior:** Explain what you want to happen instead.

### Pull Requests

1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (`pytest tests/`).
5. Make sure your code adheres to standard Python styling (e.g., PEP 8).

## Development Environment Setup

1. Fork and clone the repo.
2. Run `python3 -m venv .venv` to create a virtual environment.
3. Activate the environment (`source .venv/bin/activate` or `.venv\Scripts\activate`).
4. Install dependencies: `pip install -r requirements.txt`.
5. Install in editable mode: `pip install -e .`

Thank you for contributing!
